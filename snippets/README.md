# CSS-сниппеты

Включаются в **Настройки → Внешний вид → CSS-сниппеты**. Ползунки настроек: плагин **Style Settings**.

- **`fixed-media-size.css`** — ограничивает размер картинок и видео (по умолчанию 350 px). Если ширина задана вручную (`![[img.png|600]]`), ограничение не действует.
- **`media-grid-snippet.css`** — собирает подряд идущие картинки и видео в сетку. Работает только в режиме чтения. Между группами оставляйте пустую строку.
- **`sanctum-theme_custom-settings.css`** — мелкая косметика для темы Sanctum reborn: свойства и теги.
- **`accent.css`** — акцентный цвет одним списком для светлой и тёмной темы (Style Settings → Accent), плюс серые тона светлой темы и оформление главной страницы.
